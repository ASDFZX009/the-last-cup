# ถ้วยสุดท้าย — The Last Cup

เกมเว็บแนวอนิเมะ cozy mystery ผสมวิชวลโนเวล คุณรับช่วงร้านกาแฟเล็กๆ ต่อจากคุณยาย แล้วพบว่าหลังเที่ยงคืน ลูกค้าของร้านคือวิญญาณที่ยังมีเรื่องค้างคาใจ คุยกับแขก เก็บและต่อ "เศษความทรงจำ" แล้วชงเครื่องดื่มที่ใจเขาตามหา

## เล่นยังไง
เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร (ภาพ เพลง และเสียงทั้งหมดสร้างด้วยโค้ด)

หรือเปิด GitHub Pages: Settings → Pages → Branch `main` / root

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ฉาก หน้าจอ UI และสไตล์ทั้งหมด |
| `js/art.js` | ตัวละคร ฉากย้อนอดีต ภาพวาดสีเทียน ของตกแต่ง |
| `js/data.js` | เนื้อเรื่อง "ถ้วยสุดท้าย" (5 คืน 4 วัน) |
| `js/data2.js` | เนื้อเรื่อง "แมวดำที่จางหาย" (ปลดล็อกหลังจบเรื่องแรก) |
| `js/story.js` | คัตซีน บันทึกประจำวัน เรื่องเล่าของแขก |
| `js/engine.js` | ระบบเกม: บทสนทนา การชง มินิเกม เซฟ เสียง |
